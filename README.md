# Juego de Colores (EXAMEN PARCIAL)

El juego consiste en seleccionar el color correcto antes de que termine el tiempo. 
El jugador debe obtener la mayor cantidad de puntos posibles en 30 segundos.
---
# Tecnologías utilizadas
- Kotlin
- Jetpack Compose
- Navigation Compose
- MVVM
- StateFlow
- SharedPreferences
- Material 3
---
# Pantallas de la aplicación

## WelcomeScreen
Pantalla inicial con:
- título del juego
- instrucciones
- botón para iniciar a jugar

## GameScreen
Pantalla principal del juego:
- temporizador
- imagen/color aleatorio
- botones de respuesta
- puntaje actual

## ResultScreen
Pantalla final:
- puntaje obtenido
- historial de partidas
- mejor puntaje
- botón para volver a jugar
